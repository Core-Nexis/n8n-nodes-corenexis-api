# Changelog

## 0.1.0

First release.

- Corenexis API node with ten resources: Account, Markdown to PDF, HTML to PDF, Image to Text (OCR), PDF to Text
  (OCR), Email Validator, Disposable Email Detector, Image Conversion, Image CDN, and QR Code and Barcode.
- Every option of each API, with the plan requirements noted on the options that need a paid plan.
- Binary file input for documents, images and PDFs; hosted results can be downloaded into the item as binary files.
- PDF to Text: Extract Text and Wait, Submit Job and Get Job, with webhook support.
- Credential check through the free account endpoint, spending no quota.
- Usable as a tool by the n8n AI Agent.
